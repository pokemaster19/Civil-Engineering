# ControlSystem

📋 Overview

ControlSystem is a full-stack web application designed for managing building defects and construction projects. It provides a complete lifecycle management system from defect registration through resolution tracking and reporting.
🎯 For Whom?

    Engineers — Register and update defects, attach documentation

    Managers — Assign tasks, monitor deadlines, generate reports

    Leadership — View progress analytics and performance metrics

✨ Key Features
🔐 Authentication & Authorization

    JWT-based authentication with refresh tokens

    Role-Based Access Control (RBAC) — Admin, Manager, Engineer roles

    Password security — bcrypt hashing with salt

    Session management — Configurable token lifespan

📌 Defect Management

    Create, edit, and track defects with full history

    Status workflow — New → In Progress → Review → Closed

    Priority levels — Critical, High, Medium, Low

    Assignment system — Assign tasks to team members

    Deadline tracking — Visual indicators for overdue items
